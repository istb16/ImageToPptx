# ImageToPptx
画像ファイルをPPTXへ変換するコンソールアプリケーションです。

## 使い方
ImageToPptx.exeへ画像ファイルをドラッグ＆ドロップしてください。画像ファイルと同じ場所に同じ名前でpptxファイルが生成されます。
また、コンソール上で下記方法でも実行できます。

> ImageToPptx.exe 画像ファイル名.jpg

## 動作環境
.NET 10 ランタイム（Windows）が必要です。

## リリース
main に push（PR をマージ）すると GitHub Actions がビルドし、最新の `v*` タグのパッチ番号を 1 つ上げたタグ（例: `v1.0.1` の次は `v1.0.2`）で、`ImageToPptx.exe` を添付したリリースを作成します。

マイナー・メジャーバージョンを上げるときは、`v*` 形式のタグ（例: `v1.1.0`）を main のコミットに付けて push してください。そのタグでリリースを作成し、以降のパッチ番号はそのタグから数えます。
